IWC Artist Scraper

Extract Artist username and avatar URL from IWC store pages

How to use

  1. Open iwantclips.com in this same browser and click "Enter the site" on the age gate popup. You only need to do this once.
  2. Come back to this file and paste your list of store URLs below - one URL per line.
  3. Click "Extract data" and wait for all URLs to be processed.
  4. Click "Copy for Sheets" - then open your Google Sheet and press Ctrl+V (or Cmd+V on Mac).
This tool must be opened as a local file in your browser (not uploaded anywhere). The browser needs to be the same one where you accepted the IWC age gate.

# Username Avatar URL Status

Status: OK = data found - No data = page loaded but selectors not matched - Error = page could not be fetched (age gate not accepted or network issue)
